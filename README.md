## Datei-Cloud

Die Website enthält eine gemeinsame Datei-Cloud (Tab „Cloud"): hochladen,
ansehen, herunterladen darf jeder Angemeldete – löschen nur der Eigentümer
(serverseitig erzwungen). Die Einrichtung mit einem kostenlosen
Supabase-Projekt ist in [CLOUD-ANLEITUNG.md](CLOUD-ANLEITUNG.md) beschrieben;
Sicherheits- und Funktionstests liegen unter `tests/`.
